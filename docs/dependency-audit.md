# Аудит зависимостей

`npm audit` для каталога `web` сообщает об одной уязвимости высокого уровня.

| Зависимость | Идентификатор | Риск | Затронутые версии | Статус |
|---|---|---|---|---|
| `source-map-js` | [GHSA-68fv-2mgg-jv7q](https://github.com/advisories/GHSA-68fv-2mgg-jv7q) | отказ в обслуживании через смещения секций indexed source map | `>=1.0.0 <1.2.2` | исправление доступно |

Зависимость транзитивная. Обновление не входит в изменение инфраструктуры
тестирования и должно выполняться отдельной задачей с проверкой совместимости
инструментов сборки Web UI.
